# Future growth backlog

These ideas are intentionally outside the two-week MVP.

## Data expansion

- Add hospital/procedure detail from B.C. and Nova Scotia open data.
- Add Ontario CSV dashboard exports.
- Add Quebec wait-list snapshots as a separate prospective-wait module.
- Add hip-fracture repair and selected cancer surgeries.
- Join population, workforce, hospital-bed and health-spending data.

## Engineering

- Automate source downloads and file-version logging.
- Produce Parquet outputs and incremental DuckDB refreshes.
- Add stronger schema validation and source-specific tests.
- Schedule a monthly or annual refresh workflow.

## Analytics and modelling

- Calculate waiting-list rate per 100,000 residents.
- Add lagged features and completed-volume predictors.
- Compare Ridge, Elastic Net and time-series models.
- Add rolling-origin backtesting and forecast intervals.
- Build capacity and demand scenarios.

## Product

- Add hospital drill-down dashboard pages.
- Build an optional Streamlit public demo.
- Add bilingual English/French labels.
- Add downloadable summary reports and accessibility testing.
